================================================================
ACCEPTANCE CRITERIA (AC1 — FR-24, D10.3)
================================================================
- POST /payments/{id}/page-tokens → { pageToken, pageUrl } (createPageToken on
  the port; mock mints a one-time token, HTTP POSTs the endpoint). ✓
- Mobile WebView loads `pageUrl` → onLoadEnd → POST /payment-page-sessions
  { pageToken } (exchangePageToken) sets the rb_pay cookie so the SAME FE
  payment page is reused inside the WebView. One-time token: a reused/unknown
  token is rejected PAYMENT_PAGE_TOKEN_INVALID (verified). ✓
- Timer stays server-authoritative across the handoff: it is computed from
  paymentExpiresAt + serverTime (ServerClock), not a client clock, so moving
  into the WebView never resets it (unchanged from RBT-060). ✓
- SNAP success/failed return routes via onNavigationStateChange →
  /success or /expired (resolveWebViewNav, unit-tested). The FE never marks
  PAID itself (RBT-063 verifies). ✓
- Web: no WebView handoff (the browser is already on the page) → a plain notice.

Clean-Arch: OpenPaymentWebView use case framework-free; the <WebView> + platform
split confined to the screen; port methods grounded in the Payment Service
OpenAPI (PageToken, PageSessionRequest). O2 endpoints flagged — mocked until BE.

HONEST NOTE: both native shots show a BLANK WebView. This is expected and
correct for mock-first: the mock `pageUrl` is a relative in-app path
(`/payment/<id>?rb_pay_token=...`), NOT a real http(s) SNAP page, so a native
WebView has nothing loadable to render. The WebView component DOES mount and
attempt the load (the integration is wired), but real rendered content requires
the real O2 SNAP endpoint, which is not delivered. The full RBT-062 behaviour —
token mint, WebView mount, onLoadEnd token exchange, one-time-token rejection,
success/failed nav routing, web vs native split — is proven by the RNTL suites
(PaymentWebViewScreen.test.tsx, usePaymentWebView.test.tsx,
open-payment-webview.use-case.test.ts) and the http/mock adapter tests.
