ACCEPTANCE CRITERIA
================================================================
AC1 — WCAG 2.1 AA on web:
  - Live regions (accessibilityLiveRegion="polite" → aria-live on web) on the
    status-change surfaces: queue status/position (Waiting), countdown timers
    (Checkout/Payment TopBar), error banners (Home/Checkout/Payment), AND — added
    here — the verify/processing status on PaymentResult + Success. ✓
  - Status never color-only (WCAG 1.4.1): LIVE/SEDANG-BERLANGSUNG labels, payment
    states carry text, e-ticket has a text ref. The a11y test asserts the
    ExpiredRecovery status is conveyed by a text header, not color. ✓
  - Contrast / focus order / keyboard nav: theme tokens + button roles are in
    place; measured contrast + web tab-order are MANUAL items in the checklist. ✓(built-in) / manual
AC2 — native screen-reader + reduced motion:
  - Interactive controls expose accessibilityRole + accessibilityLabel
    (buttons, QR card, back/pay/retry/re-queue/snap actions) — enforced by the
    new a11y test. Headers use role="header". ✓
  - Reduced motion honored via useReducedMotion() across HeroCarousel, Reveal,
    ScreenFade, TrustStrip, Waiting, + the poll-cadence floor. ✓
  - Masked NIK / safe QR ref only — no raw PII in the a11y tree (D7.1). ✓
AC3 — automated + manual:
  - Automated (CI-feasible): src/__tests__/a11y/accessibility.test.tsx asserts
    roles + labels + live regions + no-color-only status; runs in the jest gate. ✓
  - axe: N/A to React Native (no DOM) — documented; a one-off axe run on the web
    export is the recommended supplement (kept out of the cloud CI gate per
    WORKFLOW.md "no e2e/browser checks in the cloud gate"). ✓(documented)
  - Manual checklist for the rest (measured contrast, web keyboard order,
    VoiceOver/TalkBack pass): wcag-checklist.md, to run before release (RBT-084). ✓

Note: full WCAG 2.1 AA conformance requires manual AT testing + expert review —
this ticket ships + enforces the structural contract and documents the manual
items, it does not assert a conformance certificate.
